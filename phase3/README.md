# Todo App - Phase III

A modern multi-user todo application built with FastAPI (backend) and Next.js (frontend).

## Project Structure

- `/backend` - FastAPI server with SQLModel ORM
- `/frontend` - Next.js 15 application with TypeScript
- `/specs` - Specification-driven development documents

## Status

- Phase 1 (Setup): ✅ Complete
- Phase 2 (Foundation): ✅ Complete
- Phase 3 (Task CRUD): 🚧 In Progress
- Phase 4 (Frontend UI): 🚧 In Progress

## Running

Backend: `cd backend && uvicorn main:app --reload --port 8000`
Frontend: `cd frontend && npm run dev`
